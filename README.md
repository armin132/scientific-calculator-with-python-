# Scientific Calculator with Python

A desktop scientific calculator made with Python and Tkinter.

## Features

- Basic arithmetic operations
- Trigonometric functions
- Inverse trigonometric functions
- Hyperbolic functions
- Degree and radian modes
- Square root and cube root
- Logarithmic functions
- Factorial and percentage
- Memory buttons
- Calculation history
- Live result preview
- Keyboard shortcuts
- Safe expression evaluation

## Requirements

Python 3.10 or newer is recommended.

No extra packages are required.

## Run

```bash
python main.py
```

On Windows, this command can also be used:

```bash
py main.py
```

## Tests

```bash
python -m unittest discover -s tests -v
```

## Example expressions

```text
sin(30) + cos(60)
sqrt(144) + 2**8
log(1000)
factorial(6)
percent(15) * 200
pow(2, 10)
```

## Keyboard shortcuts

- Enter: calculate
- Escape: clear
- Ctrl+C: copy the result
- Ctrl+L: reset the calculator
